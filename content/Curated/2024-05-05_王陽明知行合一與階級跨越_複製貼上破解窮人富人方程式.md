## 整理版段落（由 Claudian 生成）

### 今日主要觀點
知行合一不是心靈雞湯，而是停止思考、直接複製富人的行為與位置——買房、吃飯、開車都透過環境改造而非思想修煉，實現階級躍升。銀行看的是現金流證據，不只是資產抵押；社會上的階級歧視都是窮人自己招來的（身份信號缺失）。

### 今日摘要
- 新富邦藝庭房貸 4000w，牙醫月收 80w 才有可能，普通工資無法貸——銀行需要現金流證據
- [[王陽明]]悟道的關鍵：停止不斷思考，直接模仿聖人的行動方式（複製貼上）
- 階級跨越三步法：搬去信義計畫區／大安區 → 經常吃米其林 → 開雙 B 車 → 眼界自動升級
- 銷售與畫廊看你的身份信號（開的車、穿的衣）來判斷你是否有購買力——貧窮是視覺訊號
- 底層人比有錢人更要說感謝、請對不起——越窮越需照顧別人的情緒價值

### 關鍵觀點

1. **房貸現實**
   - [[富邦藝庭]]貸款 4000w 的標準：月收 80w（牙醫等高收入者）
   - 銀行不只看房子抵押，更看**現金流證據**；需要製造「現金流的證據」讓銀行信服
   - 工資低 → 無法製造現金流證據 → 銀行拒貸，即使有房屋抵押

2. **王陽明與知行合一的破解**
   - 王陽明原本整天思考如何成聖人（朱熹理學、兵推、漢光演習）
   - 悟道時刻：不如直接看聖人每天怎麼做，**照著聖人的方式生活**
   - 知行合一 ≠ 思想與行動一致；而是**停止想，開始做**；模仿 > 思考
   - 「想再多沒屁用、知道很多更是沒屁用」——行為決定人生，不是知識

3. **階級跨越的實踐方程式**
   - **位置改造**：搬去信義計畫區／大安區（富人聚集區）
   - **消費升級**：經常吃米其林（吃裝潢而不只是食物；開眼界）
   - **身份信號**：開雙 B 車（[[巴菲特]]開 TOYOTA 是因為他有臉；你沒有臉，必須用物質信號補償）
   - **自動升級**：行為改變 → 身份信號改變 → 眼界自動打開 → 時間成本、溝通成本降低
   - **典範案例**：久哥 44 歲交不到女朋友 → 把 TOYOTA 換成雙 B → 第一個月就交到網友

4. **社會階級的真相**
   - 銷售與畫廊透過**身份信號**（開的車、走進來的方式）快速判斷客戶是否有購買力
   - **貧窮本質是視覺訊號**——不是實際窮，而是看起來窮
   - 富邦藝庭銷售故事：開 TOYOTA vs 開賓士 E300，服務態度天壤之別
   - **社會上的歧視都是自己招來的**——因為你讓人看你沒有

5. **有錢人的炫富邏輯**
   - 有錢人不低調，都在某個地方「很不經意的炫耀」（房子、藝術品、車子、錶）
   - [[郭台銘]]是最低調的 → 例外；沒有一個真正有錢人完全低調
   - 有錢人炫富不是虛榮，而是**樹立身份信號**（讓你知道他有錢，降低溝通成本）
   - 信義計畫區住戶都是幾 e 起跳，房子囤積 5～6 間（錢太多無處可去）

6. **情緒成本與階級差異**
   - 越窮越要說「請」「謝謝」「對不起」；越有錢說話越少
   - 1k 以上餐廳：久哥絕對不會說「謝謝」；1k 以下餐廳必須狠狠感謝
   - **底層人的困局**：因為窮，必須照顧別人的情緒價值（尤其是伴侶）
   - [[黃老師]]前妻很漂亮但要舔，還要買賓士給太太——錢多反而要更當舔狗（因為資不抵德）
   - 女性資源選擇論：與[[黃老師]]一樣等級漂亮的女性，還是要舔（金錢 = 承諾信號）

7. **身份信號的力量**
   - 預售屋看房：走路 / 開 TOYOTA 銷售掃你一眼 → 開賓士 E300 銷售主動指揮交通、幫指引停車位
   - 藝廊現象：來客身份不達標 → 畫廊小姐掃描評估 → 態度冷淡（白嫖客）
   - 成本評估：**社會上一切都是成本評估**，不是道德問題
   - 有錢人進貴婦百貨存停車位問題 → 但銀行黑卡有尊貴停車位權限 → 節省時間成本
