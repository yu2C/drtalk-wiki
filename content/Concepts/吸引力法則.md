## 定義

不是透過禱告、祈求、或冥想就能實現願望，而是靠「意志力 + 觀察力 + 行動」的複合。

久哥的核心觀點：
> 「心想事成不是靠禱告、祈求，而是靠自己的努力得來。要先有自己的意志力、野心，有野心你才會往目標做，有做才有機會。」

## 核心機制

1. **意志力（野心）** — 內心要先形成清晰的 view（願景）
2. **觀察力** — 「想要賺錢就要不斷注意自己」，敏銳捕捉機會訊號
3. **行動** — 當機會出現時，有膽識執行

## 生活應用案例

### 攝影修煉（2010 年實踐，2024-01 補充）

[[久方武|久哥]]的親身案例，驗證吸引力法則的核心機制：

- **形成願景（意志力）**：想要把攝影學好，日思夜想
- **觀察力**：每天睡眠只有 5 小時，滿腦子都是攝影構圖、光影、技巧
- **行動**：持續修煉 1.5 年，分秒必爭地創作
- **結果**：短期內掌握了攝影技藝，有成績出來

**機制驗證**：不是祈禱或冥想，而是「日思夜想 + 觀察 + 行動」的三角融合

### 加密貨幣研究（2022 年 1 月開始，2024-01 補充）

同樣的模式應用到金融領域：

- **形成願景**：下定決心要掌握加密貨幣與 Web3
- **觀察力**：每天睡眠只有 4-5 小時，做夢跑步都在想加密趨勢、項目評估、市場機會
- **行動**：日以繼夜地研究、交易、參與生態
- **結果**：短期內成為加密領域的認知專家，掌握 [[認知套利]] 機會

**深層含義**：
- 吸引力法則不是心想事成，而是「頻率對齊」
- 當你全力專注於一個目標，潛意識會自動捕捉相關的訊號與機會
- 機會靠近不是巧合，而是你的觀察力強化到無法忽視

### 身體自動改變呼吸法
- 久哥內心默念腹式呼吸法 ← 形成 view
- 兩天內持續觀察自己的肚子 ← 觀察力
- 早晨起床身體自動改變呼吸法 ← 潛意識行動
- 結果：鼻塞、鼻竇炎改善

### 經濟狀況改變
- 久哥「二年前想要變有錢就真的有錢了」
- 這是認知 + 行動的長期累積，而非超自然現象

## 與投資的關連

在市場上，吸引力法則表現為：
- **財神爺/趨勢來的時候，要很小心注意不要讓他跑掉** ← 觀察力
- **順勢而為不要逆勢** ← 與趨勢（大的吸引力）同向
- 看到賣壓很重時就順勢做空 ← 行動力

## 消費快樂與賺錢動力的悖論（2023-11）

**哈佛商學院論述**：「為什麼你會窮？因為你花得太少」
- 享受 fine dining、精品消費的人，身體會「記住」這個舒適度
- 無意識地去追求維持這種生活 → 自然產生更高的賺錢動力
- 反例：「住淡水省錢、每天吃滷肉飯」的人，永遠無法開發出賺錢動力

**機制**：
- 消費快樂 ≠ 浪費，而是信號傳遞
- 身體 > 大腦，身體記憶決定無意識行動
- 享受當下的人反而更積極追求更高目標

**與招神咒/招魔咒的關連**：
- 招魔咒（負面）：恐懼貧窮 + 過度節儉 = 吸引貧窮
- 招神咒（正面）：享受當下 + 清晰目標 = 吸引富裕

## 常見誤區

❌ 吸引力法則 = 冥想禱告祈求  
✓ 吸引力法則 = 意志力驅動的觀察 + 行動

❌ 「想著就會來」  
✓ 「想著 → 觀察 → 做 → 才會來」

## 招魔咒 vs 招神咒的雙面性（2023-11；2025-12 補充怨力機制）

> 「你是在施展招魔咒還是招神咒？」

同樣的吸引力法則機制，可以向兩個方向運作：

### 招魔咒（負面吸引）
- 恐懼、貪心、自我懷疑 → 吸引失敗、貧窮、被騙
- 「自己都認為自己做不到，怎麼可能達成？」
- 心靈上的奴性與依賴（奶頭樂馴化）
- **怨力（內在抱怨）** → 大腦分泌壓力激素 → 細胞接收信號 → 免疫力崩壞 → 吸引同類疾病
  - 醫生救人無數卻得病：來自過勞產生的怨力（抱怨薪資低、房價高、認可度不足）
  - 怨力不是「業報」，而是身體訊號系統被頻率污染

### 招神咒（正面吸引）
- 清晰願景 + 強大信心 → 吸引機會、資源、同道人
- 知行合一：先看對，再做對
- 執行力決定成敗；屏蔽無效信息、感謝批評者的 debug 指點，專注修煉
- **化解業力**：快速行動 + 停損 + 認錯 = 怨力消散
  - 加密虧損？尋根源 → 停損 → 焦慮消失，業力解除
  - 把難題當白帽駭客的恩惠 → 感謝 → 怨力轉正能量

**破局路徑**：[[自覺]]（認錯速度 > 理論知識）+ [[心靈環保]]（拉黑、刪除、封鎖無效信息）+ [[超前部署]]（機會只給有準備的人）
