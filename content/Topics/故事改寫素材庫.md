## 這個主題在整理什麼

**故事改寫素材庫**把 [[Topics/故事]] 中的長表格，轉成適合短影音、文章、podcast 開場的素材入口。這裡不追求完整記錄，而是標出每則故事的 hook、衝突、可延伸觀念與公開風險。

## 改寫欄位

| 欄位 | 用途 |
|------|------|
| hook | 3 秒內抓注意力的開場 |
| conflict | 故事中的矛盾、誤判或階級衝突 |
| concept | 可連到的 Wiki 觀念 |
| format | 適合短影音、長文、podcast 或圖文 |
| risk | 公開風險：低 / 中 / 高 |

## 改寫原則

- 先抽出普遍觀念，再回到故事，不要只講八卦。
- 涉及私人關係、性別評價、可識別人物時，優先改寫成匿名情境。
- 每則故事至少連回一個 Concept，讓短影音能導回 Wiki。
- 高風險故事只放內部，不直接公開。
