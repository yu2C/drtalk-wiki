# 日本觀察與移居戰略

[[久方武]]對日本的核心立場：**東京是台灣人最理性的海外移居地**。文化親近、生活品質高、房產可當消費品而非投機工具、且作為台灣地緣政治危機的 Plan B。

## 核心觀點

### 為什麼是日本（東京）

| 評估維度 | 久哥觀點 |
|---------|---------|
| 文化親近度 | 台灣人最容易適應：語言、食物、生活習慣高度相似 |
| 安全性 | 犯罪率極低；有秩序感的城市 |
| 生活品質 | 東京物價雖高但品質對應；食材等級完勝台灣 |
| 外資開放 | 日本歡迎外資購房；相比歐美限制少 |
| 地緣風險 | 台灣海峽若有事 → 日本是最近的民主避難地 |
| 人才引進 | 日本政府積極引進外國人才（比台灣政府更歡迎） |

### 東京 vs 台灣比較（久哥直述）
- 「東京租房品質屌打信義區」— 同等租金，東京環境完全不同層次
- 「台灣人出生就輸了，去東京才知道什麼叫生活」
- 日本文化：純真感、不市儈、做生意有道義 → 台灣越來越市儈化
- 花粉症：巧克力（90% 可可）療法在關東地區驗證有效
- 四季分明 → 對身體修煉、認知更新有物理影響（台灣無法複製）

### 移居實戰資訊

#### 簽證策略
- **經營管理簽證**：需投資 500 萬日元設立公司
- **永住**：10 年連續居住 → 最穩定選項
- **藝術家簽證**：需作品紀錄與展演證明
- **高度專門職**：IT 技術者、研究者積分制
- 久哥計劃：拍賣公司（需融資 1.5e 台幣）→ 藝術事業作為簽證基礎

#### 選區指南

| 區域 | 特色 | 久哥評價 |
|------|------|---------|
| 港區（麻布十番 / 六本木） | 最高端外資聚集地 | 「位置決定階級的物理體現」 |
| 代官山 | 精品街區、設計品味 | 品味修煉的街道環境 |
| 目黑 / 中目黑 | 目黑川沿岸、生活感 | 高 CP 值的品質地段 |
| 世田谷 | 公園多、一戶建多 | 適合養小孩的環境 |
| 白金台 | 安靜、高端住宅 | 低調有錢人聚集 |

#### 一戶建 vs 公寓（マンション）

| 比較 | 一戶建 | 塔樓公寓 |
|------|--------|---------|
| 土地擁有 | 有（永久） | 無（共有） |
| 管理費 | 無 | 每月高額 |
| 隱私 | 高 | 低（牆薄、鄰近） |
| 維修責任 | 自己 | 管理委員會 |
| 久哥偏好 | **首選**（真正擁有土地）| 次選 |
| 適合 | 長居、自住 | 投資、出租 |

#### 生活成本概估（東京港區）
- 租金：30~50 萬日元/月（1-2 LDK 好地段）
- 食材：比台灣貴，但品質天差地別
- 外食：1,500~3,000 日元正餐；米其林 15,000+ 日元
- 交通：西瓜卡搞定，不需要買車

### 日本房產觀
- **消費品邏輯**：買日本房 = 買生活環境，不是買增值工具
- **外資競爭**：歐美資本 + 中國資金湧入東京 → 港區已有共識溢價
- **貶值不怕**：日元弱 → 外資購買力增強 → 房價有撐
- **久哥最終決策**（2025）：麻布十番 / 六本木一丁目附近一戶建

## 日本文化觀察

### 久哥的日本觀
- **純真感**：日本人保有一種台灣已失去的誠實與質樸
- **職人精神困局**：日本百年老店倒閉 = 職人精神 > 創新（缺乏連續式創新）
- **女性觀察**：日台女性差異顯著（見[[Topics/兩性]]）
  - 日本女性：端莊、符合傳統女性美德的比例更高
  - 台灣女性：都市化後急速改變中
- **美食文化**：和牛入門、食材等級、米其林精神不同於台灣

### 地緣政治 Plan B 邏輯
- 1995 潤八月（台海危機）教訓：**事先準備好 > 事後逃難**
- 台灣若有事：最快 6 個月內緊張 → 需要預先在日本建立據點
- 不是「逃跑」，是「超前部署」：提前移居 = 多一條選擇
- 廈門 Plan B（中國關係惡化）→ 東京是更安全的備案
