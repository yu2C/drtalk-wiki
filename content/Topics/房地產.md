# 房地產

[[久方武]]對房地產的核心立場：**台灣房地產已進入末期、不適合作為投資工具**。資產配置應轉向 BTC + 加密貨幣。日本東京是移居與資產避險的最佳出口。

## 核心觀點

### 台灣房市論斷
- **末期宣言**（2024）：央行七度打房 + 新青安槓桿套牢 → 台股決定台灣房市，股市崩先，房市後崩
- **流動性問題**：房子賣不掉 = 資金凍死；比股票風險高十倍（股票秒賣，房子要等）
- **新青安陷阱**：年輕人用槓桿入場 → 套牢 → 未來長期賣壓
- **人口結構**：少子化 + 高齡化 → 20~30 年後鄉下房子無人接盤
- **豪宅稅下沉**：課稅結構改變，富人出走，中產套牢

### 選房邏輯（如果要買）
- **位置 > 一切**：信義計畫區 / 天母 / 大安 / 港區這種頂層才保值
- **面積策略**：小房（套房）租金報酬率 > 大房；大房流動性差
- **建商品牌溢價**：二代接班型建商（如文華院）愛面子不惜血本，品質有保障
- **環境決定身份**：和誰住在一起決定你的圈層，差一條街差天差地

### 台灣 vs 日本房產對比

| 指標 | 台灣 | 日本（東京） |
|------|------|------------|
| 定位 | 投資工具（過去式）| 消費品（理性觀點） |
| 流動性 | 差（打房政策） | 正常市場 |
| 政府態度 | 管制 + 課稅 | 開放外資 |
| 外資競爭 | 低 | 高（全球資本湧入） |
| 升值邏輯 | 通膨 + 稀缺（特定區域）| 地段 + 外資敘事 |
| 久哥建議 | 不買 / 等崩盤 | 可買（港區、麻布、代官山）|

### 房產 vs BTC
- **BTC = 全球共識**；台灣房地產 = 地區性資產，受限人口與政策
- 資金自由度：BTC 秒入出；房子動則半年～一年
- 長期來看：BTC 上漲曲線 >> 台灣任何房產

## 區域深度解析

### 信義計畫區
- 台北最高密度有錢人聚集；環境決定品味修煉
- 超慢跑場景：洗淨怨力、觀察消費行為、練習階級眼光
- 女性現象：溫良恭儉讓 = 有篩選機制的消費環境

### 淡水
- 久哥長居之地；房價相對低但有景觀優勢
- 政治訊號指標：地方議題反映全台趨勢
- 小房 + 高報酬率的資源套利窗口

### 東京（詳見 [[Topics/日本]]）
- 港區 / 麻布十番 / 代官山 / 六本木 = 位置決定階級的物理體現
- 一戶建 vs 公寓的選擇邏輯（詳見日本 Topic）

### 中國房市（警示案例）
- 恒大崩盤 = 龐氏終局的教科書
- 習近平打壓房地產 → 台灣不應幸災樂禍（下一個是誰？）
- 中國房子越來越便宜 → 外資機會窗口（冷靜觀察，不入場）

### 曼谷 / 海外佈局
- 世界房地產大未來：東南亞 + 日本 + 加拿大
- 台灣護照優勢：免簽 + 相對有資金 → 選擇彈性大
