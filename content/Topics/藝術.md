# 藝術投資與品味修煉

[[久方武]]的藝術收藏與評論實踐，涵蓋藝術品投資、當代藝術市場現況、品味修煉、藝術家評斷標準等多個維度。

## 核心觀點

### 藝術品評斷三要素
1. **獨特性** — 一眼就認得出來的個人風格
2. **歷史性** — 能說出故事與背景脈絡
3. **技術手法** — 扎實的執行能力

### 藝術 vs 消費品
- **藝術品**：獨一無二、保值增值、背後有思想支撐、敘事力
- **消費品**：本質貶值，包含高端名牌

### 有錢人的終局
- 資金自由度達成 → 資產配置進入藝術領域 → 品味修煉 → 頂級社交圈層
- 判斷力與品味在熊市比金錢更值錢

### 藝術市場現況困局
- **淘寶化威脅**：複製、量化導致無價
- **原創性稀缺**：大多數都是抄來抄去
- **日韓落後歐洲**：品質差異明顯
- **數位藝術 = 未來趨勢**：國外都在拼數位，台灣仍拼美學（落伍）

### 被忽視的寶藏：激浪派（Fluxus）
- [[Ay-O]]：彩虹表現全球第一、比[[草間彌生]]更有原創性與歷史意義
- 缘故：敘事力缺失；草間因 LV 合作而紅，Ay-O 被遺忘
- **重估路徑**：正式博物館展出（如 M+ 美術館）、國際畫廊推動、品牌合作

### 成功案例：小山登美夫畫廊
- [[小山登美夫]]為代理的藝術家們創造敘事力
- [[奈良美智]]、[[村上隆]]等當代大咖都是被他炒上來的
- 示範了「如何通過敘事與推廣打造藝術家價值」

### 建築 = 最偉大的雕塑
- [[安藤忠雄]]、[[高地]]、[[柯比意]]
- 公共財（如機場）無法私人擁有，但建築圖紙可以交易
- 活著的建築師（如安藤忠雄）比已故大師風險更低

### 藝術與商業結合
- **數位 IP 模式**：賣圖案 → 印成 T-shirt、版畫、攝影 → 壞了重印（服務化）
- **酒店與品牌合作**：高端酒店與藝術家的策略合作
- **難度對比**：搞藝術比推加密貨幣項目更難（無法只靠 FOMO）

- [[久方武]] — 收藏家、創作者、藝術市場觀察者
- [[小山登美夫]] — 日本重要畫廊老闆，代理奈良美智、村上隆

- 小山登美夫畫廊 — 當代藝術大咖搖籃
